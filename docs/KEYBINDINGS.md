# Shell keybindings

## fzf

| Shortcut | Action                                 |
| -------- | -------------------------------------- |
| Ctrl+T   | Find file (fd), insert path at cursor  |
| Alt+C    | Find directory (fd), cd into selection |
| Ctrl+R   | Search command history                 |

## Custom functions

| Command | Action                                   |
| ------- | ---------------------------------------- |
| `fn`    | Fuzzy-find files, open selection in nvim |

## Yazi

| Command | Action                                    |
| ------- | ----------------------------------------- |
| `y`     | Open yazi; cd into last directory on exit |
